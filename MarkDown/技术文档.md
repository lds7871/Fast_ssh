# SSH快连 技术文档（Fasst_ssh）

> .NET MAUI Android SSH 客户端：连接页输入 IP/用户名/密码 → 终端页用完整的终端模拟器（xterm.js）操作服务器。
> 本文档面向**用户与 AI**，帮助快速了解项目架构、每个文件的作用与关键设计。最后更新：2026-09-18。

---

## 1. 项目简介与技术栈

| 项目 | 说明 |
|---|---|
| .NET MAUI | 目标框架 `net10.0-android`（Linux 上模板自动只保留 Android 目标），SDK 10.0.112 + `maui-android` 工作负载 |
| **SSH.NET** 2026.0.0 | 纯托管 SSH 库：`SshClient`（连接/命令）、`ShellStream`（交互式终端流）。**注意：新版已移除 `ShellStream.ResizeTerminal`，改用 `ChangeWindowSize(cols, rows, w, h)`** |
| **Fleck** 1.2.0 | 轻量 WebSocket 服务器库：在 app 内起一个 `ws://127.0.0.1:22886` 服务，桥接 WebView 与 SSH |
| **xterm.js** 5.5.0 + addon-fit 0.10.0 | 浏览器/WebView 内运行的正规终端模拟器（支持 ANSI 颜色、光标、滚动、自适应尺寸），打包进 app assets 离线使用 |
| Microsoft.Maui.Controls / Logging.Debug | 模板自带 |

**总体架构（数据流）**

```
ConnectPage（连接表单）
   │  SSH 连接（TCP:22，后台线程）
   ▼
SshSession（SshClient + ShellStream）
   │  终端输出（含 ANSI 转义序列）
   ▼
TerminalBridge（Fleck 本地 WebSocket 服务器 127.0.0.1:22886）
   │  ws:// 文本帧
   ▼
TerminalPage（WebView + xterm.js，页面来自 Resources/Raw/www/index.html）
```

关键点：**xterm.js 在 WebView 里做全部终端渲染**（VT100 转义解析、光标、滚动条、颜色），app 侧只负责「SSH 字节流 ⇆ WebSocket 文本帧」的搬运，因此终端行为与桌面端浏览器一致，`vim`/`htop`/`top` 等全屏程序也能正常工作。

## 3. 核心服务：SshSession.cs

单例 `SshSession.Instance`，持有：

- `SshClient _client` —— 连接本身（`ConnectionInfo.Timeout=15s`、`KeepAliveInterval=30s` 保活）
- `ShellStream Shell` —— 交互式终端流，由 `OpenShell(cols, rows)` 创建：
  `CreateShellStream("xterm-256color", cols, rows, 0, 0, 8192)`
- 对外方法：`Connect(host, port, user, pass)`、`OpenShell`、`ResizeShell(cols, rows)`（调 `ChangeWindowSize`）、`Disconnect()`

所有方法包在 `lock(_lock)` 里，`Disconnect` 幂等（重复调用安全）。网络阻塞操作（`Connect`/`OpenShell`）由调用方放入 `Task.Run` 后台线程执行。

---

## 4. 核心服务：TerminalBridge.cs + 桥接协议

Fleck 启动一个绑定 `127.0.0.1:22886` 的 WebSocket 服务器（仅本机可访问），维护已连接客户端列表，负责：

- **收到消息（JS→C#）**：
  - 以 `\u0000resize:` 开头 → 解析 `cols:rows` → `SshSession.ResizeShell()`
  - 否则 → `shell.Write(message)`（即终端输入）
- **广播（C#→JS）**：把 `ShellStream` 读线程收到的输出 `Send` 给所有 WebSocket 客户端（xterm.js 直接渲染）

读线程逻辑（TerminalPage.PumpShellToClients）：用 `StreamReader` 包 `ShellStream` 阻塞 `Read`（StreamReader 负责 UTF-8 多字节边界），`_bridge.IsRunning` 为 false 或连接关闭时退出。

## 5. 终端宿主页面：Resources/Raw/www/index.html

WebView 加载 `file:///android_asset/www/index.html`（MauiAsset 把 `Raw/www/**` 原样打进 assets）。页面职责：

1. 创建 `Terminal` 实例（xterm.js），加载 fit 插件，`term.open()` 后 `fit.fit()` 计算真实 cols/rows；
2. 建立 `WebSocket('ws://127.0.0.1:22886')`，断线自动重连（`connect()` 循环），连接前输入进 `pending` 队列；
3. `term.onData` → `sendInput()`（统一发送入口，带 Ctrl/Alt 组合逻辑）→ `ws.send(data)`；
4. 窗口变化（旋转/软键盘）→ `fit.fit()` → 发 `\u0000resize:cols:rows`；
5. **功能键接口** `window.__key(kind)`，供 C# 的 `EvaluateJavaScriptAsync` 调用：
   - `up/down/left/right` → `\x1b[A/B/C/D`（方向键转义序列）
   - `ctrl` / `alt` → 切换 Ctrl/Alt 组合模式（切换式，Termux 风格）：
     - Ctrl 模式下 `onData` 把单个字母转成控制字符（`c`→`\x03` Ctrl+C）
     - Alt 模式下单字符前加 `ESC` 前缀（`x`→`\x1bx`）

## 6. 页面生命周期与状态管理

- **ConnectPage.OnAppearing**：回填上次输入（进程内 static 记忆；勾选「记住输入」才写 Preferences 持久化）；若已有会话则先断开（从终端页返回时清理）。
- **TerminalPage.OnAppearing**：`StartTerminalAsync()` → ①启动 TerminalBridge → ②`OpenShell(80,24)` → ③启动读线程 → ④设置 WebView.Source（首次）或调 `window.__reconnect()`（复用）。
- **断开/返回**：点「断开」或 Android 返回键 → `SshSession.Disconnect()` + `TerminalBridge.Stop()` + 导航回连接页；`OnDisappearing` 兜底再清理一次（幂等）。
- 固定深色主题：`App` 构造里 `UserAppTheme = AppTheme.Dark`，无主题切换按钮。

## 7. 构建与真机调试

```bash
# Debug（可直接安装；注意默认 Fast Deployment 会导致真机 "No assemblies found"，务必加参数）
dotnet build -f net10.0-android -c Debug -p:EmbedAssembliesIntoApk=true

# Release（正式签名：密码走环境变量 SSH_KEYSTORE_PASS，见 csproj）
SSH_KEYSTORE_PASS=xxx dotnet build -f net10.0-android -c Release
```

真机调试（adb 位于 `~/Android/Sdk/platform-tools/adb`）：

```bash
adb install -r bin/Debug/net10.0-android/com.companyname.fasst_ssh-Signed.apk
adb shell monkey -p com.companyname.fasst_ssh -c android.intent.category.LAUNCHER 1   # 启动
adb logcat -d | grep -i fasst_ssh                                                      # 看日志
```

读取 WebView 里 xterm 的屏幕内容（Debug 构建 WebView 自动开调试端口，可验证终端输出/功能键转义序列）：

```bash
adb forward tcp:9222 localabstract:webview_devtools_remote_$(adb shell pidof com.companyname.fasst_ssh)
# 再用 WebSocket 客户端连 http://127.0.0.1:9222/json 里的 page target，发 CDP Runtime.evaluate，
# expression: document.querySelector('.xterm-rows').innerText
```
